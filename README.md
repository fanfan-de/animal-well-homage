# 动物井 · 致敬复刻（Animal Well Homage）

一个从零写的、可玩的《动物井》(ANIMAL WELL, Billy Basso) 风格类银河战士恶魔城小游戏。
**没有任何图片或音频文件**：所有像素画都是源码里的 ASCII 画，所有音效和氛围音乐都由 WebAudio 实时合成。

- 分辨率 320×176（8px 地砖，40×22 格），整数倍缩放
- 34 个手绘房间、5 件道具、4 团火焰、12 颗蛋、6 个存档电话
- 动态光照（蜡烛、灯笼、鞭炮、火焰）、水、单向平台、按钮/拉杆/门、隐藏墙
- 8 种动物：幽灵猫、狗、鸟、蜗牛、鱼、海马、变色龙、鸵鸟（没有战斗，只有躲避与利用）
- 房间切换滑屏、地图、存档（localStorage）、结局

## 运行

```bash
pnpm install
pnpm dev        # 开发：http://localhost:5173
pnpm build      # 产出 dist/index.html —— 单文件，双击即可离线游玩
```

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 跳跃（按住跳得更高） | Z / 空格 / K |
| 使用道具 | X / J（按住 ↓ + X 可以把飞盘放在脚边） |
| 切换道具 | C / L / Shift，或 1–5 直接选 |
| 从单向平台落下 | ↓ + 跳 |
| 存档 / 放置火焰 | ↑（在电话 / 基座旁） |
| 地图 | M / Tab |
| 暂停 | ESC / P |

也支持手柄（左摇杆/十字键、A 跳、X 道具、LB/RB 切换、Start 暂停、Select 地图），触屏设备会自动显示虚拟按键。

## 流程（剧透）

从井心出发：鞭炮（井道）→ 泡泡棒（西·泡泡洞）→ 飞盘（东·犬舍，需泡泡）→ 灯笼（南·灯笼祭坛，需飞盘）与溜溜球（北·溜溜球之间，需飞盘打碎裂墙）→ 四团火焰（海马、猎犬、鸵鸟、变色龙）→ 放回井心的基座。

## 代码结构

```
src/engine/   通用引擎：输入、像素画布/精灵光栅化、粒子、WebAudio 合成
src/game/     游戏：常量、调色板、ASCII 精灵、地砖、房间解析、物理、实体、玩家、光照、HUD、存档、主循环
src/game/rooms/  关卡数据（每个房间 22 行 × 40 列的 ASCII 地图 + 图例）
scripts/validate.ts  关卡校验：尺寸、出口对齐、基于跳跃模型的可达性、道具门控、软锁检查
scripts/e2e.sh       端到端测试：无头 Chrome 跑脚本化输入并输出状态
scripts/shot.sh      无头 Chrome 截图
```

## 验证

```bash
pnpm check      # 类型检查
pnpm validate   # 关卡校验（-v 显示每个房间的到达轮次，-dump=3,2 打印某房间可达格子）
pnpm build && pnpm e2e        # 端到端场景（需要本机的 Google Chrome）
pnpm shot "room=3,3&frames=30" /tmp/a.png   # 截图
```

调试参数（加在 URL 后）：`?room=3,3&x=120&y=100&items=all&eggs=8&keys=1&flames=all&nolight=1&frames=120&script=r:30,rj:14,r:20&log=1&state=map`
